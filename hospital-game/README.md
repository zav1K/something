# Нічна зміна (робоча назва)

VHS-хоррор від першої особи в стилі Chilla's Art: інтерн-лікар на нічному чергуванні в старій
районній лікарні, десь на межі 90-х і 00-х. Знято на особисту відеокамеру — звідси й VHS-фільтр
(сканлайни, шум, хроматична аберація, тремтіння трекінгу).

## Статус

Чорновий блокаут усієї будівлі (CSG-примітиви, без фінальних текстур/детального реквізиту):

- **Підвал** — морг, склад, пральня, харчоблок
- **1-й поверх** — приймальне відділення, реєстратура, рентген-кабінет, санпропускник,
  кабінет головного лікаря
- **2-й поверх** — Терапія 1 і Терапія 2 (по 5 палат, пост медсестри, сестринська,
  ординаторська, маніпуляційна, санвузол/душова в кожній)
- **3-й поверх** — хірургічне відділення, реанімація, операційний блок
  (передопераційна, операційна, стерилізаційна, перев'язочна)
- **Дах** — доступний лише з лівих службових сходів
- Центральні сходи (парадні, з ліфтом) + ліві/праві службові сходи
- Перший сестринський пост детально продресований (лампа, папки, старий телефон)
- Кольорова схема стін взята з реальних фото діючих українських лікарень
  (звіти омбудсмена): зелена емаль знизу + побілка зверху

## Що ще потрібно

- Текстури/детальний реквізит для решти кімнат (зараз лише базові меблі Kenney Furniture Kit)
- Фізичні крапки в сходинках (зараз — похилі пандуси-заглушки замість East східців)
- Візуальна модель ліфта + його логіка
- Сюжетні тригери/записи/документи по кімнатах
- Геймплейний цикл чергування (обходи, дзвінки, кава/перекур)

## Як відкрити

Потрібен [Godot 4.7+](https://godotengine.org/). Відкрити `project.godot` в редакторі.
Рендер-метод — GL Compatibility (потрібно для вебекспорту, але добре працює і в десктоп-білді).

Керування: WASD — рух, миша — огляд, клік по екрану — захоплення курсора, Esc — відпустити.
